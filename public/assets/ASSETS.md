# 비주얼 에셋 기록

V48 에셋은 내장 이미지 생성 도구로 제작한 오리지널 SD 애니메풍 시안이다. 배경, 각 인물, 아이템 격자를 별도 파일로 관리한다. 최종 배포 전 생성 서비스 약관과 개별 에셋의 권리 및 유사성을 검토한다. 생성 이미지를 MIT 라이선스라고 표시하지 않는다.

| 파일 | 생성 요청 요지 |
| --- | --- |
| `backgrounds/selection-v2.png` | 캐릭터가 없는 밝은 초원 마을, 캐주얼 애니메 판타지 배경 |
| `characters/illustrations/sword-sd.png` | 갈색 긴 머리, 흰색·파란색 갑옷과 검을 든 SD 검사 아린, 투명 배경 전신 |
| `characters/illustrations/archer-sd.png` | 짙은 녹색 긴 머리, 숲색 가죽옷과 활을 든 SD 궁수 세린, 투명 배경 전신 |
| `characters/illustrations/mage-sd.png` | 은색 긴 머리, 남색·금색 의상과 수정 지팡이를 든 SD 마법사 루나, 투명 배경 전신 |
| `items/inventory-atlas.png` | 3열 2행 순서의 나무, 약초, 광물, 나무 검, 갑옷, 회복 물약 아이콘 |

인벤토리는 격자를 CSS로 나눠 표시하므로 각 아이콘을 별도 파일로 저장하지 않는다. 3D 외형은 현재 이미지와 색상과 실루엣만 맞춘 임시 코드 모델이며 완성 모델이 아니다.
