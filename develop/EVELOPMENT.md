# 온라인 생활형 RPG 기능 요구사항

**현재 문서 버전: V50**

## V50 작업 대상 — 로그인과 첫 화면

- **REQ-18-01:** 계정 로그인에서 캐릭터 선택으로 원활히 진행하고 서버 버전 불일치를 알린다.
- **REQ-18-05:** 플레이어는 첫 화면에서 배경이 보이는 고정형 로그인 UI를 사용한다.

## V49 작업 대상 — 실제 게임 접속과 조작

- **REQ-18-01/02:** 계정 로그인 후 캐릭터를 생성·선택하고 캐릭터별 진행을 보관한다.
- **REQ-18-03/04:** 카메라 기준 여덟 방향 이동과 게임 HUD·퀵슬롯을 제공한다.
- **REQ-17-02/03:** 일러스트를 닮은 SD 외형과 직업별 행동을 개선한다.

## V48 작업 대상 — SD 애니메풍 게임 화면

- **REQ-17-02, REQ-17-03:** 개별 캐릭터 이미지와 SD 외형, 직업별 전투 효과를 개선한다.
- **REQ-17-05:** 배경과 선택한 캐릭터의 전신 일러스트를 조합해 보여준다.
- **REQ-17-06:** 재료와 장비, 소모품을 구분할 수 있는 아이콘을 인벤토리에 표시한다.

## V47 작업 대상 — 캐릭터와 움직임

- **REQ-17-01:** 플레이어는 이름과 역할이 있는 검사·궁수·마법사 캐릭터를 보고 선택해 플레이한다.
- **REQ-17-02:** 플레이어는 선택한 캐릭터의 오리지널 2D 일러스트와 이에 닮은 3D 외형을 확인한다.
- **REQ-17-03:** 플레이어와 주변 사람은 캐릭터의 대기·이동·공격·기술 모션과 직업별 효과를 볼 수 있다.
- **REQ-17-04:** 플레이어는 3D 공간을 이동할 때 카메라와 캐릭터의 움직임을 부드럽게 볼 수 있다.
- **REQ-08-01, REQ-07-04:** 캐릭터 선택과 직업별 기술·효과를 게임에 연결한다.

## V46 작업 대상 — 인게임 우선

- **REQ-07-05:** 몬스터가 플레이어를 발견·추적·공격하고, 플레이어가 공격을 보고 피할 수 있다.
- **REQ-07-01/02:** 몬스터의 현재 위치·행동과 피해 결과를 확인한다.
- **REQ-05-01/06:** 몬스터가 안전 구역을 침범하지 않고 활동 범위를 벗어나면 돌아간다.
- **REQ-07-08:** 여러 플레이어가 같은 몬스터의 움직임과 전투 상태를 본다.

이번 단계는 운영 기능보다 인게임 플레이의 기초를 우선한다.

## 문서 사용법과 상태

- 기능은 플레이어 또는 운영자가 **무엇을 보고, 선택하고, 할 수 있는지**로 쓴다. 기술 설계·폴더 구성·라이브러리는 [README](../README.md)에 둔다.
- `[ ]`는 미구현 또는 일부 구현, `[x]`는 기재한 기능이 코드상으로 모두 구현된 상태다. 체크는 실제 플레이·보안·성능 시험 통과를 뜻하지 않는다. 일부만 구현되었다면 체크하지 않고 진행 상황을 적는다.
- 실제 검증은 필요한 항목을 모아 진행하고 결과를 아래 검증 기록에 남긴다. 체크된 기능도 검증에서 문제가 발견되면 다시 연다.
- 각 요구사항의 고유 REQ 번호를 유지하고, 구현이나 변경 시 해당 항목 아래에 버전별 이력을 누적한다. 문서를 수정하는 작업마다 최상위 버전을 올리고 날짜·시각, 대상 번호와 작업을 기록한다.
- 모든 요구사항이 코드상 완료되고 남은 작업이 없으면 반복 요청이 오더라도 새 요구사항이나 버전을 억지로 만들지 않고 완료 상태를 알린다. 미검증 사항이 있다면 별도로 명시한다.
- 추가 요구사항과 변경은 이 파일에 직접 반영한다. 별도 버전 문서를 만들지 않는다. 순서와 범위는 개발 중 수정할 수 있으며 항목이 너무 크면 사용자 행동 단위로 나눈다.
- 현재 개발 우선순위는 필드·전투·성장·생활 등 인게임 플레이 구현이다. 운영·문의 기능은 게임 진행에 직접 필요한 경우를 제외하고 후순위로 둔다.
- 우선순위: **필수**는 첫 공개 가능한 게임의 기본 흐름, **확장**은 기본 흐름을 갖춘 뒤 추가하는 장기 목표, **운영**은 운영자·콘텐츠 담당자 기능이다. 나열 순서가 출시 일정의 확정은 아니다.
- 이 목록은 현재 기획 기준의 전체 범위이며, 실제 출시 가능 여부는 완성도·운영·보안·접근성·권리 및 적용 지역의 조건도 함께 판단한다. 각 기능을 체크했다고 자동으로 상용 서비스 준비가 완료되는 것은 아니다.

## 현재 구현과 검증 상황

초기 프로토타입에는 가입·로그인, 계정당 캐릭터 하나 생성, 3D 이동과 이름 표시, 몬스터 공격·마법, 경험치·레벨, 채집·검 제작·장착, 캐릭터 저장, 서버 상태 API의 기초 코드가 있다. 캐릭터 선택 폭, 저장 실패 대응, 화면·콘텐츠의 완성도 등은 부족하므로 아래의 넓은 요구사항을 완료로 간주하지 않는다. 최근 추가한 게임 기능의 두 창 플레이, 재접속 저장 및 외부 DB는 실사용 검증 전이다. 계정은 남지만 기존 초기 프로토타입 위치는 새 캐릭터에 자동 이전되지 않는다.

- 코드 검사와 빌드는 해당 시점의 기초 확인이며 위 기능의 실사용 성공을 대신하지 않는다. 추후 검증 시 날짜, 버전, 환경, 결과와 남은 문제를 이 절에 추가한다.
